# ExecPlans

For complex work, keep a self-contained plan in `exec-plans/active/`. Record the objective, necessary context, scope, execution steps, progress, relevant decisions, and validation. Update progress and decisions as work proceeds.

When finished, append the final implementation outcome and validation results, including deviations and unresolved limitations, then move the plan to `exec-plans/completed/`. Existing completed plans remain historical records. Track concrete unresolved technical debt separately in [the debt tracker](exec-plans/tech-debt-tracker.md).
